# Serene Drives - Peaceful 3D Driving Experience

A visually stunning 3D driving game built with Three.js that focuses on relaxation and exploration rather than competition.

## Features

- Beautiful 3D environments with dynamic weather and day/night cycles
- Realistic physics with satisfying driving mechanics
- Multiple camera angles for different perspectives
- Customizable car appearance and performance
- Soothing ambient soundtrack and nature sounds

## Installation

1. Make sure you have Node.js installed on your system
2. Clone or download this repository
3. Navigate to the project directory in your terminal
4. Run `npm install` to install dependencies
5. Run `npm start` to start the server
6. Open your browser and go to `http://localhost:3000`

## How to Play

- Use W/A/S/D keys to drive
- Space for handbrake
- R to reset your car
- C to change camera views

## Browser Compatibility

This game works best in modern browsers that support WebGL:

- Firefox 65+
- Safari 12+
